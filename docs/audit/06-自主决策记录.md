# 06 · 自主决策记录

- 日期：2026-11-12
- 记录本次执行中影响方向的关键判断、绕过的坑和遗留项。不是“待确认清单”。

## 1. 先留副本，再动工程

- 解压后先 `cp -a` 到工作目录，`git init` 并提交原始基线（commit `baseline: original 3z9wOpt v1.1.0 snapshot`）。
- 同时保留 `_archive/original-3z9wOpt-v1.1.0/` 完整副本。
- 决策理由：任务要求“改动前留可回滚副本”；git 便于逐文件 diff，archive 便于整目录对照。

## 2. 改名策略：全库替换 + 人工复核

- 批量替换 `3z9wOpt/3z9wopt/3z9wOptV11/无名大叔/...` → `ahtool/ah系统优化工具箱`。
- 之后单独处理危险项：域名（不能跟着变成 `ahtool.com`）、版本号、外链、联系方式、Logo。
- 决策理由：机械替换快，但 URL/品牌/版权必须人工判断；最终 `grep` 残留为 0（历史误报证据除外）。

## 3. 服务端绑定：**移除而不是改域名**

- 选择：重写 `service.go`、`design/svc.js`、`design/about.js`，删除 `tools/relgen`、`build_frontend.js`、旧发布文档与素材。
- 不选择“保留功能只换域名”，原因：
  1. 没有二次开发者的真实域名/证书/清单，保留空壳会制造“假更新/假服务”；
  2. 原服务大厅是付费远程服务转化页，与“干净二次开发基线”目标冲突；
  3. 移除后仍有单测 override 通道，未来恢复更新不需要重写代码。
- 在线更新：保留代码但 `updateEnabled=false`、`updateManifestURL=""`；单测通过 `updateManifestURLOverride` 注入本地 httptest，通道未堵死。
- 关于页：只展示版本/构建/许可/SHA256，不展示联系方式。

## 4. 版本：单一真源 `APPVER=1.0.0`

- `build.cmd` / `build.ps1` / `build.sh` 里只写一次 `APPVER`，通过 `-X main.appVersion` / `buildDate` 注入。
- 前端版本从 `GetAboutInfo()` 读，去掉硬编码 fallback（保留“版本未知”）。
- 保留 `buildNum` 变量与旧测试（兼容历史），但本分支发布不再生成构建号；不再调用 `tools/relgen`。
- `app.manifest` 四段版本改为 `1.0.0.0`；`rsrc.syso` 用 `go-winres` 重建。

## 5. 安全修复：只做“低风险、可验证”的部分

已修：
- 卸载命令不再 `cmd /c` 原串；裸命令只接受 System32（`appclean.go:1296-1320`）。
- 强制清理/残留清理目录加 `resDirSafe`/运行时保护/重解析点（`appclean.go`）。
- `deepjunk` 加保护（`junk_clean.go:1042`）。
- 特权删除加 `FILE_FLAG_OPEN_REPARSE_POINT`（`junk_priv.go`）。
- 注册表删除区分“不存在/拒绝访问”（`junk_reg.go:530`）。
- 停用明文公网 IP 查询（`speedtest.go`）。

未修（写进报告与待办，不在本轮强行改）：
- `SpaceDelete` 会话令牌/系统目录硬拦截（改动涉及前端协议，需设计）。
- 优化项原值快照（改动 154 项数据模型，工作量大）。
- 驱动 `/force` 占用检查（需枚举设备，需真机验证）。
- `winold`/`SpaceOpen` 的 cmd 拼接（需原生 API 替代）。

决策理由：本轮目标是“可继续二次开发的干净基线”，不是一次性重构所有安全边界；把高风险但需要设计/真机验证的项明确交给下一轮，避免改出不可验证的半成品。
