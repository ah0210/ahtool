## 解压后构建

```bat
build.cmd release
```

或：

```powershell
pwsh -File build.ps1 -Release
```

```bash
GOPROXY=https://goproxy.cn,direct ./build.sh release
```

要求 Go 1.26+（`golang.org/x/sys v0.48.0` 硬性要求）。

## 可复现性验证

已把本包解压到临时目录，用包内源码重新执行：

```powershell
go build -buildvcs=false -trimpath -tags desktop,production `
  -ldflags "-s -w -H windowsgui -X main.appVersion=1.0.0 -X main.buildDate=2026-11-12" `
  -o ahtool.exe .
```

结果：重建 exe 与包内 `bin/ahtool_v1.0.0.exe` 的 SHA256 **完全一致**：

```
dcfd8159dab0d041dc278974c3ce067ccee45d71551e1684ec360870a5e30af6
```

前提：同一 Go 1.26.x 工具链、同一 `-buildvcs=false -trimpath` 参数。
