## 一、本轮新增功能

### 1. 本机配置 → 网络与音频

新增「详细网络与安全」卡片，只读展示：

- 计算机名 / 域；
- 每块网卡：描述、类型、状态、速率、MAC、DHCP/静态、IPv4、IPv6、子网、默认网关、DNS、DHCP 服务器、DNS 域、WINS；
- 代理：系统代理、代理服务器、PAC、绕过列表、WinHTTP、环境变量；
- 防火墙：域/专用/公用配置文件状态；
- hosts 自定义条目数与示例；
- 本地服务器：localhost、本机名、SMB、网关、DHCP、DNS；
- TCP 监听端口（前 40）；
- 安全提示：代理/PAC/hosts/防火墙/SMB1/远程桌面/无 DNS 等。

数据源：`Win32_NetworkAdapterConfiguration`、注册表、`netsh winhttp`、`wevtutil` 不涉及；全部本机读取，不上传。

### 2. 工具库 → 上不了网

新增两个工具（工具总数 34 → **36**，net 分类 7 → **9**）：

| ID | 名称 | 行为 |
|---|---|---|
| `net-dnsclear` | 清除 DNS 解析缓存 | `ipconfig /flushdns`，只清缓存，不改 DNS/hosts |
| `net-dnsmon` | DNS 解析监控器 | 轮询 `ipconfig /displaydns` 5 分钟，只显示新增解析，只读、不上传 |

`toolkit_test.go`、`testdata/golden_tools.json`、前端症状分组、README 已同步。

### 3. 磁盘 I/O 模式文案与保护

- 模式说明改为：静音/保护、均衡（默认）、极速（仅建议 SSD/NVMe）；
- 检测到机械盘时，界面提示“极速不会更快，只会更响/更卡”；
- 选择极速且存在 HDD 时，二次确认；
- 明确“模式只影响扫描/删除并发，不改变删除范围”。

## 二、关键修复

- WMI 数值属性读取：`VARIANT.ToString()` 只支持 BSTR，改为 `variantText()` 用 `Value()` 兜底；物理盘 MediaType/BusType/HealthStatus 不再 Unknown。
- WMI 数组属性：IP/DNS/网关等 `VT_ARRAY` 现在会展开为逗号分隔字符串。
- 修复启动阶段可能因 WMI 数组类型（VT_ARRAY|VT_VARIANT / 数值数组）被误按 BSTR 读取而触发的访问违例；`GetPCFull` / `GetNetworkInfo` 增加 panic recover，失败时页面显示“网络信息读取失败”，不再让窗口消失。
- 修复 `NetEnabled` 布尔值大小写导致网卡状态误判为“未连接”。
